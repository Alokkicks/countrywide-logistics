# Logistics Management System

A modern web-based logistics management system designed to simplify shipment tracking, employee workflows, and business operations.

## 🚀 Features

### 🌐 Customer Side
- Shipment tracking interface
- User-friendly homepage
- Easy access to shipment information

### 👨‍💼 Employee Dashboard
- View recent shipments
- Monitor upcoming shipments
- Access important shipment information
- Quick actions for daily operations

### 🛠️ Admin Dashboard
- Business and operational overview
- Manage logistics workflows
- Monitor shipment-related activities

### 📦 Shipment Workflow
The project is designed around a structured logistics workflow:

1. Create Shipment
2. Verify Shipment
3. Dispatch Shipment
4. Update Delivery Status

This helps keep shipment operations organized and easier to manage.

## 🎯 Project Goal

The goal of this project is to build a practical and user-friendly logistics management platform that demonstrates how different parts of a logistics business can be managed through dedicated interfaces for customers, employees, and administrators.

## 💻 How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is currently required.
